# Public page artwork

The Landing and login layout restore the brand design first released on
2026-09-20. The Landing keeps the Earth positioning fix released on 2026-09-22.

- horizon-photo.webp: NASA/JSC photograph
  [ISS074-E-0089803](https://images.nasa.gov/details/iss074e0089803), taken
  January 16, 2026. Credit: NASA. The original 4928×2768 photograph was resized
  to 2400 pixels wide and encoded as WebP. The Landing footer links to the source.
  Its use does not imply NASA endorsement.
- horizon.webp: generated Earth artwork for the login brand panel.
- noto-sans-sc-landing.woff2: the original local Noto Sans SC variable subset.
  Characters outside this subset fall back to the existing Gabugu Sans SC font.
  See noto-sans-sc-OFL.txt for the font license.
- inter-latin.woff2: the existing local Inter font. See Inter-LICENSE.txt.
- gabugu-logo-dark.png and gabugu-logo-light.png: the existing current
  Gabugu marks. The restored pages use the dark-surface mark and preserve a
  configured custom site logo.
